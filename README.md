# YULIM AI BUYER OS — MVP 2차 버전

## 실행
- `index.html`을 더블클릭하면 브라우저에서 실행됩니다.
- GitHub Pages에 올리면 웹앱으로 사용할 수 있습니다.
- `assets/yulimit_logo.png`는 사용자가 제공한 YULIM 공식 로고 원본입니다.

## 핵심 기능
1. 구매 대시보드
2. 구매 조건 상담(외부 AI가 아닌 로컬 규칙 기반)
3. 상품 탐색 및 등록
4. 선택 상품 비교
5. 수동 가격 추적
6. 구매 요청 및 승인 단계 관리
7. 견적 요청 등록 및 공급업체별 견적 비교
8. 공급업체 관리
9. 구매 분석 및 CSV 내보내기
10. 견적에서 발주 대기 건 생성 및 발주·납품 상태 관리

## 데이터 및 주의사항
- 데이터는 브라우저 LocalStorage에 저장됩니다. 다른 직원 기기와 자동 동기화되지 않습니다.
- 실시간 최저가 검색, 자동 이메일, 실제 AI 모델, 다중 사용자 권한/승인은 연결되어 있지 않습니다.
- 샘플 데이터는 데모용입니다. 실제 업무 데이터로 전환하기 전에 샘플을 정리하고 백업하세요.
- `데이터 백업`으로 JSON 파일을 주기적으로 내려받으세요.
- 실제 고객정보, 계약정보, 개인정보 등 민감정보는 현재 버전에 입력하지 마세요.
