# YULIM AI BUYER OS — Free MVP

## 실행
- `index.html`을 더블클릭하면 브라우저에서 실행됩니다.
- GitHub Pages에 올리면 웹앱으로 공유할 수 있습니다.
- `assets/yulimit_logo.png`는 사용자가 제공한 YULIM 공식 로고 원본입니다.

## 포함된 9개 기능
1. 구매 대시보드
2. AI 구매 상담(현재는 규칙 기반 조건 정리)
3. 상품 탐색 및 등록
4. 상품 비교
5. 가격 추적(수동 입력)
6. 기업 구매 관리
7. 견적 요청서 작성·인쇄
8. 공급업체 관리
9. 분석 리포트 및 CSV 내보내기

## 데이터와 한계
- 데이터는 현재 브라우저의 LocalStorage에 저장됩니다.
- 다른 직원의 PC/휴대전화와 자동 동기화되지 않습니다.
- 실제 AI 모델, 실시간 쇼핑몰 최저가 검색, 자동 가격 수집, 이메일 발송은 연결되어 있지 않습니다.
- 이 버전은 기능 검증용 MVP이며, 실제 고객·민감정보·계약정보를 입력하지 마세요.
- `데이터 백업` 버튼으로 JSON 백업을 자주 내려받으세요.

## GitHub Pages 배포
1. GitHub에서 `yulim-ai-buyer-os` 저장소를 만듭니다.
2. 이 압축 파일을 풀고 파일 전체를 저장소 최상위에 업로드합니다.
3. Settings → Pages → Deploy from a branch → `main` / `/(root)` 선택 후 저장합니다.
4. 잠시 뒤 `https://khlee-74.github.io/yulim-ai-buyer-os/`에서 확인합니다.
